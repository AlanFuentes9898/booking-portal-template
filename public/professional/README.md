## Image format tips

- **JPG** is fine (size matters more than format for photos).
- Compress at 80-85% quality. Target <200KB per image.
- Use [Squoosh.app](https://squoosh.app/) for quick optimization.
- For consistent crops, use a tool like Photoshop or Figma export at the
  exact aspect ratios above.

## If the client doesn't have professional photos yet

- Sugest a photo session (~$3-5k MXN for a 1-hour shoot).
- **Temporary fallback:** use Unsplash (free, high quality):
  - Hero (img-1): search "professional portrait <vertical>" e.g. "nutritionist"
  - About: same person, different angle
  - Clinic (img-5): search "<vertical> office", "<vertical> consultation room"
- Mark in the handoff message that these are temporary stock photos and
  should be swapped for real ones within 2 weeks.
